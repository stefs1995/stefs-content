STEFS CONTENT - cara pasang di HP

Isi: 7 file (index.html, manifest.webmanifest, sw.js, 3 gambar ikon, panduan ini).
Upload semua file langsung ke repo, tanpa dimasukkan ke folder.

CARA 1 (paling mudah): GitHub Pages
1. Buat repo baru di GitHub, misalnya "stefs-content".
2. Upload semua isi folder ini (index.html langsung di root repo).
3. Settings > Pages > Source: Deploy from a branch > main > /root > Save.
4. Tunggu 1-2 menit, buka https://USERNAME.github.io/stefs-content/ di Chrome HP.
5. Menu titik tiga > "Install app" / "Tambahkan ke layar utama".
6. Buka sekali saat online. Setelah itu aplikasi jalan offline.

CARA 2 (jadi file APK): PWABuilder
1. Pastikan Cara 1 sudah jalan (butuh link https).
2. Buka pwabuilder.com, tempel link tadi, tekan Start.
3. Pilih Package for stores > Android > Generate.
4. Unduh paketnya, ambil file .apk, kirim ke HP, lalu install
   (izinkan "install dari sumber tidak dikenal").

CATATAN
- Data (kartu, foto, video) tersimpan di HP, bukan di server.
- Kalau data situs Chrome dihapus, atau aplikasi diinstall ulang, data ikut hilang.

BACKUP DAN PULIHKAN
- Tombol panah turun di pojok kanan atas aplikasi.
- Simpan backup: membuat satu file .stefs (kartu + foto + video) di folder Download.
  Simpan juga di Google Drive atau kirim ke chat dirimu sendiri.
- Pulihkan: pilih file .stefs. "Gabungkan" memperbarui kartu yang sama dan menjaga kartu lain.
  "Ganti semua" mengganti data sekarang dengan isi backup.
- Titik merah di tombol berarti sudah lebih dari 7 hari sejak backup terakhir.
- Update aplikasi: upload ulang semua file ke repo, lalu buka aplikasinya dua kali.

LIHAT BESAR, UNDUH, SALIN
- Tap foto atau video di kartu (atau di editor) untuk melihat besar. Ada tombol Unduh dan Bagikan.
- Di editor, tombol "Unduh semua" mengunduh semua media kartu, dan "Salin semua teks" menyalin judul, catatan, dan hashtag.

FITUR TAMBAHAN
- Penghitung karakter: di kolom Catatan / caption, maksimal 500 tapi boleh lebih. Kalau lewat, tampil selisihnya (contoh -23).
- Performa: di kartu Viral ada Views, Likes, Klik link, Komisi, dan catatan hasil.
- Duplikat: tombol di editor kartu, membuat salinan dengan foto/video yang sama.
- Arsip: tombol Arsip di kolom Done. Bisa arsipkan Done yang lama (7/14/30 hari) sekaligus, dan kembalikan kapan saja.

URUTAN PRIORITAS DAN TANGGAL UPLOAD
- Drag kartu ke atas atau bawah kartu lain di kolom yang sama untuk mengatur prioritas. Garis warna menunjukkan posisi jatuhnya. Urutan tersimpan.
- Cadangan: di editor kartu ada tombol Naikkan dan Turunkan.
- Tanggal upload: isi di editor kartu. Di kartu tampil kecil, misalnya "Upload 13/10/26". Hari ini diberi garis, yang sudah lewat (selain Done dan Viral) berwarna merah.

HARI INI, REKAP, TEMPLATE, PENYIMPANAN (baris tombol di bawah tab kolom)
- Hari ini: kartu yang terlewat, jadwal hari ini, dan 7 hari ke depan. Angka merah = yang perlu diupload. Tombol "Sudah upload" memindahkan kartu ke Done.
- Rekap: total komisi, views, klik, dan rasio klik, lalu per produk (#). Bisa diurutkan, tap satu baris untuk melihat kartunya.
- Template: simpan kerangka caption. Di editor kartu tap "Template caption" untuk memasukkannya. Bagian "..." langsung terpilih untuk diganti. Template ikut tersimpan di backup.
- Penyimpanan: ukuran foto dan video, kartu paling besar, dan status perlindungan data.

LOKASI DATA DI HP
- Kartu, foto, dan video disimpan di penyimpanan privat Chrome untuk situs github.io-mu. Tidak muncul di Galeri atau File.
- Cek ukuran: Pengaturan HP > Aplikasi > Chrome > Penyimpanan, atau Chrome > titik tiga > Setelan > Setelan situs > Semua situs.
- File hasil Unduh dan Backup ada di folder Download.
- Menghapus data Chrome atau data situs ikut menghapus semua kartu. Simpan backup dulu.
